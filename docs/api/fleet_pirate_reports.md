# /api/fleet/pirate-reports

Returns pirate combat report feed.

## Method

`GET`

## Query Parameters

```text
page={number}
limit={number}
```

## Response Structure

```json
{
  "reports": [],
  "unreadCount": 0
}
```

## Notes

- Live-validated on `s0` (200).
- Current account sample had no pirate reports.
